# HiG Sign — электронная подпись Homes in Georgia

Договор открывается у каждого подписанта прямо в Telegram (Mini App): читает, расписывается пальцем,
ставит галочку согласия. Когда подписали все стороны, телефон последнего подписанта собирает PDF, и он:

- сохраняется на Google Диске компании, договор и подписанты — в реестре (Google Таблица);
- приходит в Telegram всем подписантам и вам.

Личность каждого подписанта подтверждает Telegram: данные Mini App подписаны ключом бота и проверяются на сервере.
Если указан @username, подписать сможет только этот аккаунт.

| Тип | Кто подписывает | Текст |
|---|---|---|
| **NDA агента** (`nda-agent` v1.1) | агент, затем компания — Давид Тибелашвили (@davidtibelashvili) | шаблон: грузинский слева, русский справа |
| **Договор аренды** | арендатор и собственник, в любом порядке | ваш готовый PDF — текст не меняется, подписи добавляются внизу каждой страницы |

В итоговом PDF подписи всех сторон стоят внизу каждой страницы, в конце — протокол подписания
(личный номер, телефон, Telegram ID, время сервера, IP, устройство, хэш документа, подпись).

Ссылку подписанту можно отправить кнопкой **Telegram** или **WhatsApp** (на его номер). Подписывают в Telegram.
Подпись через WhatsApp с кодом подтверждения — следующий этап (WhatsApp Business API от Meta).

## Что сделать один раз (≈15 минут)

### 1. Бот подписи — в @BotFather
1. `/newbot` → имя `Homes in Georgia Sign`, username например `homesingeorgia_sign_bot`. Сохраните **токен**.
2. `/newapp` → выбрать этого бота → название `HiG Sign`, описание, картинка 640×360 (любая из бренда) →
   **Web App URL:** `https://platformdge.github.io/hig-sign/sign.html` → short name: `sign`.

### 2. Сервер — Google Apps Script
1. script.google.com → **Новый проект** «HiG Sign».
2. Создать два файла и вставить код: `Code.gs` и `Templates.gs` (из папки `apps-script`).
3. Вверху выбрать функцию `setup` → **Выполнить** → разрешить доступ.
   В журнале появятся ссылка на реестр и **пароль админ-панели**.
4. Настройки проекта → **Свойства скрипта** → добавить:
   - `SIGN_BOT_TOKEN` — токен из шага 1;
   - `BOT_USERNAME` — `homesingeorgia_sign_bot` (без @);
   - `APP_SHORT_NAME` — `sign`;
   - `ADMIN_CHAT_IDS` — ваш Telegram ID (узнать: написать @userinfobot); несколько — через запятую.
     Перед этим напишите своему боту `/start`, иначе он не сможет вам писать.
5. Выполнить `testTelegram` — бот пришлёт «связь работает».
6. **Развернуть → Новое развертывание → Веб-приложение**: «Выполнять от имени: меня», «Доступ: все».
   Скопировать URL (`…/exec`).

### 3. Подключить фронтенд
В `assets/config.js` вписать `API_URL: 'https://script.google.com/macros/s/…/exec'` и закоммитить.

### 4. Работа
1. Открыть `https://platformdge.github.io/hig-sign/admin.html`, ввести пароль.
2. Заполнить ФИО, личный номер, телефон, @username агента → «Создать ссылку».
3. «Отправить в Telegram» → выбрать агента. Агент нажимает ссылку → договор открывается в Telegram.
4. Статус виден в списке и в реестре. PDF приходит вам в Telegram сразу после подписи.

> Бот не может первым написать человеку, который его не запускал, поэтому ссылку агенту отправляете вы.
> Mini App сам попросит у агента разрешение, чтобы бот прислал ему подписанный PDF.

## Обновление кода в Apps Script
Скопируйте заново `apps-script/Code.gs` и `apps-script/Templates.gs` в проект (как при установке), сохраните, затем
**Развернуть → Управление развертываниями → ✏️ → Версия: «Новая версия» → Развернуть**. Адрес `/exec` не меняется.
Листы и колонки реестра обновятся сами при первом запросе.

## Изменить текст договора
`apps-script/Templates.gs`: у каждого пункта есть `ka` и `ru`. После правки поднимите `version` и сделайте
**Развернуть → Управление развертываниями → Изменить → Новая версия**. Уже созданные договоры хранят свой текст.

## Безопасность и доказательства
- Подлинность Telegram-аккаунта: проверка HMAC-подписи `initData` (токен бота знает только сервер), срок — 24 часа.
- Хэш SHA-256 текста договора фиксируется при создании и печатается на каждой странице; хэш итогового PDF — в реестре.
- В протоколе: ФИО, личный номер, телефон, Telegram ID и @username, время сервера (Тбилиси), IP, устройство.
- Пароль админ-панели и токен бота хранятся только в свойствах скрипта, в репозитории их нет.
